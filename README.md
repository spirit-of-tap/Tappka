# Local Development

## Setup

1. Install git if already not installed - https://git-scm.com/install/
2. Install node.js v24.x if already not installed - https://nodejs.org/en/download/ (or use `nvm install` if you have nvm)
3. Install pnpm v10.x if already not installed - https://pnpm.io/installation
4. Clone the repository - `git clone https://github.com/tappka/tappka.git`
5. Navigate to the project directory - `cd tappka`
6. Install dependencies - `pnpm install`
7. Start the development server - `pnpm dev`
8. Open the project in the browser - `http://localhost:3000`
